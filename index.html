MacBook Terminal Commands

Command Example usage
pwd Run in any folder to show the current directory path.
ls -la List all files, including hidden ones, with permissions and details.
cd ~/Projects Jump directly to your Projects folder from anywhere in the terminal.
cd .. Move to the parent folder of the current directory.
mkdir -p sites/my-site Create nested folders in one step for a new project.
touch index.html styles.css script.js Create starter web files quickly in the current directory.
rm -rf build Delete the build folder and all contents when you want to rebuild output.
mv old-name.html new-name.html Rename a file or move it to a new location.
cp -R src backup/src Copy a directory and all its files recursively to a backup folder.
open . Open the current folder in Finder for easy browsing.
open index.html Open an HTML file directly in the default browser from the terminal.
code . Open the current project folder in Visual Studio Code.
git status Check which files have changed and which are staged for commit.
git add . Stage all modified files in the current directory for the next commit.
git commit -m "message" Save staged changes with a short, descriptive commit message.
brew install node Install Node.js using Homebrew for local JavaScript tooling.
sudo command Run a command with administrator privileges when needed.
history | grep git Find previous git commands in your shell history.
clear Clear the terminal screen to reduce clutter.

HTML Tag Examples

  • <!DOCTYPE html> — declares the document as HTML5 and should appear at the top of every page.
  • <html></html> — wraps the whole document and contains both the <head> and <body>.
  • <head></head> — holds metadata, page title, styles, and scripts that are not shown directly on the page.
  • <body></body> — contains visible page content like headings, text, images, and sections.
  • <header> — top banner area for a page title, subtitle or navigation.
  • <nav> — groups navigation links so users can move around the page.
  • <section> — divides content into thematic blocks, such as features, pricing, or call-to-action areas.
  • <article> — wraps self-contained content like blog posts, cards, or documentation entries.
  • <h1> to <h6> — heading tags used for page hierarchy; use one <h1> for the main title and smaller headings inside sections.
  • <p> — paragraph text for body copy and explanations.
  • <a href="https://example.com">Link text</a> — creates clickable links between pages or sections.
  • <img src="image.jpg" alt="Description"> — embeds images; always set alt for accessibility.
  • <ul><li>...</li></ul> — unordered lists for bullet points, menus, and feature lists.
  • <form>...</form> — contains input controls for user data like email, name, and messages.
  • <label for="email">Email</label> and <input id="email" type="email"> — pair labels with inputs for better usability and accessibility.
  • <button type="submit">Send</button> — submits forms or triggers actions like opening a modal.

Writing HTML Explained

  • <!DOCTYPE html> — required first line to tell the browser the page is HTML5.
  • <html lang="en"> — root element; use lang for proper language support and accessibility.
  • <head> — contains metadata such as the page title, character set, CSS links, and script references.
  • <meta charset="UTF-8"> — sets character encoding so text and symbols display correctly.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> — makes the layout responsive on mobile devices.
  • <title>Page Title</title> — shown in the browser tab and used by search engines.
  • <link rel="stylesheet" href="styles.css"> — attach external CSS for styling page content.
  • <body> — contains visible content like headings, text, media, and interactive elements.
  • <header> — use for the top part of a page or section, including titles and navigation.
  • <nav> — wrap primary navigation links to help users move around the site.
  • <main> — holds the main content. Only one <main> should appear per page.
  • <section> — group related content into topical sections like features or contact info.
  • <article> — use for independent blocks of content such as posts, cards, or docs.
  • <footer> — add copyright, secondary links, and page notes at the bottom.
  • <h1>...<h6> — heading tags define document structure; use one <h1> for the main page title.
  • <p> — paragraphs of text for body copy and descriptions.
  • <a href="https://example.com">Link</a> — create clickable links; add target="_blank" rel="noopener" for external URLs.
  • <img src="image.jpg" alt="Description"> — embed images and always provide accessible alt text.
  • <ul><li>...</li></ul> and <ol><li>...</li></ol> — use lists for grouped items and step-by-step content.
  • <form> — collects user input; pair <label> with inputs for accessibility.
  • <label for="email">Email</label> + <input id="email" type="email" name="email"> — label binding improves usability and screen reader support.
  • <button type="submit">Send</button> — use to submit forms or trigger actions.
  • Use class names for styling and IDs for unique anchors or JavaScript hooks.
  • Prefer semantic tags over generic <div>/<span> to help accessibility and readability.
  • Indent nested tags consistently and close every element to keep HTML clean and maintainable.
  • Comment with <!-- comment --> when you want to explain page structure or sections.
